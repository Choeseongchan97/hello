# 🐱 르냥뮤직스 (Renyang Musics)

르냥홀딩스의 귀여운 고양이 음악 플레이어. 오리지널 곡 **르냥골골송** 수록.

## APK 받기
[Releases](../../releases) → 가장 위 버전 → `renyang-musics.apk` 를 폰에서 눌러 설치.
(처음 설치할 때 "출처를 알 수 없는 앱 설치 허용"을 켜야 해요)

## 기능
- 폰 음악 자동 찾기 / 파일 골라서 넣기 (곡명·가수·앨범커버·가사 자동 읽기)
- 노래 · 플레이리스트 · 앨범 · 가수 · 폴더 · 즐겨찾기 · 최근 재생 · 많이 들은 곡
- 플레이리스트 여러 개 만들기, 순서 바꾸기, 지금 재생 목록 편집
- 알송식 싱크 가사 (.lrc), ±0.5초 싱크 조절, 가사 줄 눌러서 이동, 가사로 검색
- 소리 0~100 한 칸씩 조절, 5밴드 이퀄라이저 + 프리셋
- 셔플 · 반복 · A-B 구간반복 · 재생 속도 · 잠자기 타이머
- 잠금화면 · 알림창 · 블루투스 버튼으로 조작, 백그라운드 재생

## 구조
Flutter 3.27 · just_audio · just_audio_background · file_picker · permission_handler
`android/` 폴더는 빌드할 때 `ci/build.sh`가 자동으로 만들어요.
